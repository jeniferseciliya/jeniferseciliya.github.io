# Jenifer Seciliya — Portfolio Website

Recruiter-focused portfolio for Data, BI, People Analytics, Product Analytics, and
Recruitment Analytics opportunities.

The site is intentionally dependency-light: semantic HTML, custom CSS, and a small
JavaScript enhancement layer. Project previews and the résumé are hosted locally so
the portfolio remains reliable on GitHub Pages.

## Featured work

- TalentScope — People Analytics & Compensation Intelligence
- Meridian — Retail BI & AI Analytics
- Threadline — Product Analytics & Experimentation

## Local preview

```bash
python3 -m http.server 8780
```

Open `http://localhost:8780`.
